# Brand fonts

Drop these files here, then set `USE_BRAND_FONTS = true` in `src/styles/fonts.ts`.
If the supplied file names differ, rename them or update `src/styles/brand-fonts.css`.

| File | Family | Weight |
|---|---|---|
| Somar-Light.woff2 | Somar (English) | 300 |
| Somar-Regular.woff2 | Somar | 400 |
| Somar-SemiBold.woff2 | Somar | 600 |
| Somar-Bold.woff2 | Somar | 700 |
| BahijTheSansArabic-Light.woff2 | Bahij TheSansArabic (Arabic) | 300 |
| BahijTheSansArabic-Plain.woff2 | Bahij TheSansArabic | 400 |
| BahijTheSansArabic-SemiBold.woff2 | Bahij TheSansArabic | 600 |
| BahijTheSansArabic-Bold.woff2 | Bahij TheSansArabic | 700 |

Make sure the licence covers web embedding.

Note: these paths are absolute (/fonts/...), so they only resolve when the site is served from a
domain root (the client's own domain). They will not load from the iraqi98.github.io/highness-of-justice URL.
